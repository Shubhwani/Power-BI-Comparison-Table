# Power-BI-Comparison-Table
This repository contains a comparison table of commonly used charts in **Power BI** with their use cases, strengths, and ideal scenarios.

## Project Overview

The purpose of this project is to help beginners and analysts understand:

* Different types of Power BI visuals/charts
* When to use each chart
* Best practices for selecting visuals
* Comparison of chart strengths and limitations

## Included Charts

* Bar Chart
* Column Chart
* Line Chart
* Pie / Donut Chart
* Area Chart
* Scatter Plot
* KPI Card
* Table / Matrix
* Map Visuals
* Funnel Chart

## Objective

To build a quick reference guide for choosing the right visual while designing professional Power BI dashboards.
